# Client Reporting Automation

## Project Overview
An automated monthly advertising reporting system for digital marketing agencies.

## Objective
To reduce manual work involved in collecting advertising campaign data, analyzing performance, generating client reports, and delivering reports by email.

## Technology Stack
- Make.com — Workflow automation
- Google Sheets — Campaign data and KPI calculations
- Gemini — AI-powered campaign analysis
- Google Docs — Report generation
- Gmail — PDF report delivery
- Airtable — Client reporting records

## Workflow
1. Collect Meta Ads and Google Ads campaign data.
2. Aggregate campaign records.
3. Calculate advertising KPIs.
4. Generate AI-powered campaign insights.
5. Create a Google Docs report with charts.
6. Export the report as PDF.
7. Email the PDF to the client.
8. Store report details in Airtable.

## Status
Core automation implemented and tested.
